# Dotfiles

## Introduction

My personal development environment for Arch Linux.
This repository contains the configuration files, scripts, and documentation that I use while developing software.

## Goals

- Make it easy to recreate my development environment.
- Understand every tool instead of blindly copying configs.
- Improve the environment incrementally while building projects.

## Philosophy

The goal is not to build the perfect setup before writing code.
These configurations evolve alongside my projects. Whenever I notice friction in my workflow, I improve the relevant configuration.
